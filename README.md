# Eq
A native Android equalizer app built with Kotlin and Android's Equalizer audio-effect API.
Features
Dark interface
Device-supported equalizer bands (up to 10 displayed)
Frequency labels read from the active device's Equalizer effect
Presets: Flat, Bass Boost, Vocal, Rock, Pop, and EDM
Live band-level adjustment
Android 8.0 (API 26) or newer
